# 🍅 Pomodoro Timer (Tkinter GUI)

A simple and effective Pomodoro Timer built using Python and Tkinter to improve productivity using time management techniques.

---

## 🚀 Features

* ⏱️ 25-minute work sessions
* ☕ Short break (5 minutes)
* 🛌 Long break (20 minutes after 4 sessions)
* ✔️ Progress tracking with checkmarks
* 🎨 Clean and minimal GUI using Tkinter

---

## 🧠 How It Works

The Pomodoro technique follows a cycle:

1. Work for 25 minutes
2. Take a short break (5 minutes)
3. Repeat for 4 cycles
4. Take a long break (20 minutes)

This app automates the entire cycle using a timer mechanism.
